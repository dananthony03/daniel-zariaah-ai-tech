**Brief Over Tool**
One photo, one prompt, one take, and a photoreal branded video. The tool didn't do that. The brief did. Three rules:
1. Lock the camera. Every move is a chance for the model to ruin your text.
2. Freeze the background. Name everything that isn't allowed to change.
3. Limit the motion. Two blinks, one nod, still hands. Less movement looks more real.

It's a briefing skill, not a tech skill, and it's the same discipline that separates a good discovery call from a wasted one.
